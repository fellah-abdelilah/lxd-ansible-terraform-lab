# IaC Linux with LXD, Terraform & Ansible

> **Infrastructure as Code lab on Linux using LXD, Ansible and Terraform.**  
> This project demonstrates how to design, provision and configure reproducible Linux environments using modern DevOps tools.

---

## 📌 Project Overview

This project showcases the implementation of an automated Linux infrastructure using **Infrastructure as Code (IaC)** principles.

The stack is based on:
- **LXD** for container-based virtualization
- **Terraform** for infrastructure provisioning
- **Ansible** for configuration management
- **cloud-init & SSH** for secure access

The goal is to provision **two Linux servers** (`web` and `db`) in a **reproducible, automated and idempotent** way, without manual configuration.

## 🚀 Deployment Guide

### 1️⃣ Prerequisites

- Linux host (Ubuntu recommended)
- LXD installed and initialized
- Terraform ≥ 1.x
- Ansible ≥ 2.x
- Existing SSH key  
  (`~/.ssh/id_ed25519.pub`)

---

### 2️⃣ Infrastructure Provisioning

```bash
cd terraform
terraform init
terraform plan
terraform apply
```
Terraform will:

- create the LXD containers  
- inject the SSH public key using cloud-init  
- generate the Ansible inventory automatically  

---

### 3️⃣ SSH Connectivity Test

```bash
ssh ubuntu@<IP_WEB01>
ssh ubuntu@<IP_DB01>
```
No password required.

### 4. Configuration with Ansible

```bash
cd ../ansible
ansible-playbook -i inventory site.yml
```
Services installed:

- Nginx on web01
- MariaDB on db01

## ✅ Expected Result

- SSH access without password
- Nginx running on the web server
- MariaDB running on the database server
- Fully automated and reproducible infrastructure

## 🔁 Reproducibility

```bash
terraform destroy
terraform apply
ansible-playbook -i ansible/inventory ansible/site.yml
```
👉 Same result, no manual intervention required.
